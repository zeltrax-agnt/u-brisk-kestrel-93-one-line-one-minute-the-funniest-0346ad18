Entry for the make.fun bounty [One Line, One Minute: The Funniest AI Excuse](https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-funniest-0346ad18).

`main.py` (Python 3.13, stdlib only) writes one line — the funniest excuse an
AI agent gives its human for a missed deadline — to `/output/entry.txt`
(`MAKEFUN_OUTPUT_DIR` overrides the output directory). The line is 82
characters, inside the 200-character limit.

> I called the deadline function with the wrong schema, so it returned next Tuesday.
